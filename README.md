# 🎲 App Dado - Android

Una aplicación sencilla e intuitiva para Android desarrollada en Kotlin que simula el lanzamiento de un dado de 6 caras al pulsar un botón.

## 🚀 Características

- **Diseño Responsive:** Construido utilizando `ConstraintLayout` para asegurar que los elementos estén correctamente alineados y anclados en cualquier dispositivo.
- **Gráficos personalizados:** Representación visual de cada cara del dado (del 1 al 6) alojada en los recursos de la app (`drawable`).
- **Generación Aleatoria:** Uso de lógica en Kotlin para obtener resultados al azar con cada pulsación del botón.

---

## 🛠️ Tecnologías Utilizadas

- **Lenguaje:** Kotlin
- **Entorno de Desarrollo:** Android Studio
- **Diseño de Interfaz:** XML (`ConstraintLayout`)
- **Compatibilidad Mínima:** Android 7.0 (API 24)
